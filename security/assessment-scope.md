# Independent Assessment Scope

## Scope
- **Target Release:** v6.0.x
- **Critical Packages:**
  - `@di-framework/auth`
  - `@di-framework/authz`
  - `@di-framework/http`
  - `@di-framework/rpc`
  - `@di-framework/platform`
- **Exclusions:** Example apps, experimental CLI commands, and out-of-scope dependency chains.

## Methodology & Deliverables
- Independent reviewer (external or distinct community maintainer).
- Severity rubric: Standard CVSS v3.1.
- Deliverable: Sanitized final report with all Critical/High findings retested.
- Confidentiality: Sensitive findings must be reported privately via GitHub Security Advisories.
